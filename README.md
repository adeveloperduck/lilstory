lilstory

A tiny 8M parameter language model trained from scratch on tinyStories.

https://github.com/user-attachments/assets/e6d109b2-55de-4928-8806-2e4cf1094175

runs with ollama

first, install ollama if you dont have it yet

```
curl -fsSL https://ollama.com/install.sh | sh
```

then, download and run the model!
```
ollama run navthings/lilstory
```
